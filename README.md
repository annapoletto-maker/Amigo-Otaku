# Amigo Otaku | Landing Page

Landing page de uma loja fictícia de produtos de anime e cultura geek, criada como trabalho acadêmico.

## Sobre o projeto
A オタクの友人(Amigo Otaku) vende action figures, mangás, camisetas e itens de decoração dos animes mais populares. A landing page apresenta a loja e leva o visitante, por meio de um botão, ao site de vendas.

**Público-alvo:** fãs de anime, mangá e cultura geek.
**Objetivo:** divulgar a loja e direcionar o visitante para a compra.

## Funcionalidades
- Topo com o nome da loja
- Título principal em balão de fala, no estilo mangá
- Botão "Ir para a loja", que abre o site de vendas em uma nova aba
- Painéis de categorias: action figures, mangás e camisetas
- Seção de vantagens da loja
- Chamada final com um segundo botão para o site de vendas
- Layout responsivo, que se adapta ao celular e ao computador

## Tecnologias utilizadas
- HTML5
- CSS3 (Grid, Flexbox e media queries)
- Google Fonts (Dela Gothic One e Nunito)
- Ícones em SVG feitos no próprio código

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nada.
